# Boutique d’accessoires

## Présentation du projet

Ce projet consiste à développer une boutique en ligne d’accessoires avec une vitrine permettant d’afficher les produits.

## Technologies utilisées

- **Frontend :** Next.js
- **Backend :** Strapi
- **Conteneurisation :** Docker et Docker Compose

## Structure du projet

- `frontend-vitrine/` : interface utilisateur de la boutique.
- `backend-accessoires/` : gestion du contenu et des produits avec Strapi.
- `docker-compose.yml` : configuration des services Docker.

## Installation et lancement

1. Installer Docker Desktop.
2. Ouvrir un terminal dans le dossier du projet.
3. Exécuter la commande :

   ```bash
   docker compose up --build
   ```

4. Accéder à la vitrine : http://localhost:3000
5. Accéder à l’administration Strapi : http://localhost:1337/admin
